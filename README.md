# Job Market Data Pipeline

An end-to-end data engineering project that processes job market data using PySpark and Databricks.

## Tech Stack

- Python
- PySpark
- Databricks
- Delta Lake
- SQL
- Git & GitHub

## Pipeline

Raw Job Data
→ PySpark Ingestion
→ Data Cleaning & Transformation
→ Dimensional Modeling
→ Delta Lake
→ SQL Analytics

## Dataset

Public job posting dataset containing approximately 22,000 job listings.
